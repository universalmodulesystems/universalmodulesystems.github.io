Universal Vehicle Module  /  UVM Standard

One interface.
Every vehicle.

The UVM standard defines a single docking interface that simultaneously transfers mechanical shaft power, electrical energy, fluid, and data - enabling any compliant module to connect to any compliant vehicle across road, rail, marine, aviation, and stationary applications. Like USB, but for vehicle powertrains.
